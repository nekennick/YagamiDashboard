# Project Conventions

## Git Workflow
- Always create a new dedicated branch for major code changes.
- Branch name format should follow: `feature/[task-slug]` or `fix/[bug-slug]`.
- **Commit Message:** Luôn viết nội dung commit bằng tiếng Việt theo yêu cầu của người dùng (ví dụ: `feat(inventory): đồng bộ phiếu xuất hủy vào cột xuất kho`).
